Design a complete, production-quality web application called:

INTERNPRANGON
"Smart Choices for Your First Steps"

InternPrangon is an internship discovery and management platform for university students, companies/HR teams, and administrators.

This is a real university software engineering project that will eventually be implemented as a MERN-stack application.

The Figma file will become the visual source of truth for the React frontend.

==================================================
CORE DESIGN DIRECTION
==================================================

The design should NOT look like:

- a generic university portal
- a basic internship website
- a generic AI-generated SaaS dashboard
- a Bootstrap template
- a conventional admin panel
- a collection of unrelated cards

The design should feel:

- distinctive
- editorial
- premium
- modern
- confident
- youthful
- professional
- trustworthy
- spacious
- highly intentional

Use strong visual hierarchy and thoughtful whitespace.

Prefer purposeful composition over filling every available space.

Avoid excessive rounded cards, excessive gradients, excessive glassmorphism, and unnecessary decoration.

==================================================
PRODUCT
==================================================

InternPrangon helps students:

- discover internships
- search internships
- filter internships
- save internships
- apply using their saved resume
- track applications
- review companies anonymously
- view company ratings
- view average stipend information
- share interview experiences
- earn contributor points
- earn contributor badges
- view contributor rankings
- receive notifications

Companies/HR can:

- create company profiles
- submit verification proof
- wait for admin approval
- create internship listings after verification
- manage internship listings
- view applicants
- download resumes
- update application status

Admins can:

- review company verification requests
- approve companies
- reject companies
- remove fake companies
- review reported reviews
- remove fake/inappropriate reviews

==================================================
USER ROLES
==================================================

Design three distinct experiences:

1. STUDENT
2. COMPANY / HR
3. ADMIN

The experiences must share the same brand language but have different information architecture and priorities.

Student:
More expressive, approachable and discovery-focused.

Company/HR:
Professional, structured and recruitment-focused.

Admin:
Efficient, clear and information-focused.

==================================================
IMPORTANT UX PRINCIPLE
==================================================

Do not design every page as a dashboard.

InternPrangon is primarily a discovery and career platform.

The public/student experience should have strong editorial and visual storytelling.

Dashboards should be used where dashboards actually make sense.

==================================================
TECHNICAL DESIGN CONSTRAINT
==================================================

The final design will be implemented in React and connected to an existing Node.js/Express/MongoDB backend.

Therefore:

- components must be realistically implementable
- forms must be practical
- tables must be usable
- layouts should work with dynamic content
- loading states must exist
- empty states must exist
- error states must exist
- responsive behavior must be intentional

Do not design interactions that depend on impossible frontend behavior.
